A Python-based tool for extracting images and artwork from PDF documents.

**Features:**

- PDF page analysis
- Image detection and extraction
- OCR-assisted analysis
- Text / image separation
- Automated processing of large PDF collections
- Batch extraction
- Organized output

**Tech:**

`Python` `PyMuPDF` `OpenCV` `NumPy` `Tesseract OCR`

- Pagination handling
- Large-scale archival
- Resumeable collection
- JSONL data storage

### 🟦 VK Album Archiver

A Python-based VK album archiving system using the VK API.

Built to download complete photo albums while preserving the highest available image resolution.

**Features:**

- VK API integration
- Album discovery
- Automatic photo discovery
- Original / highest available resolution
- Resume support
- Duplicate protection
- Download verification
- Retry system
- Persistent download status
- Large album support
- Organized album-based storage

**Tech:**

`Python` `VK API` `REST API` `Requests` `Pillow` `JSON`
